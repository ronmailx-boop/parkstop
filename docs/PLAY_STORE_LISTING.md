# Play Store — Store Listing (טיוטה)

טיוטת תוכן להעתקה ישירה לשדות ה-Store Listing ב-Play Console. ניתן לערוך
חופשי לפני הפרסום.

## שם האפליקציה (Title, עד 30 תווים)

```
ParkStop – תזכורת חניה
```

## תיאור קצר (Short description, עד 80 תווים)

```
ParkStop מזכירה לך לעצור חניה ברגע שאתה חוזר לרכב. הכל נשאר במכשיר שלך.
```

## תיאור מלא (Full description, עד 4000 תווים)

```
שכחתם לעצור חניה? לא עוד.

ParkStop היא אפליקציה פשוטה עם מטרה אחת: להזכיר לכם לעצור את החניה
הפעילה (בפנגו, בסלופארק, ב-EasyPark, או בכל אפליקציית חניה אחרת) ברגע
שאתם חוזרים לרכב שלכם — לפני שהיא ממשיכה לרוץ ולעלות לכם כסף.

איך זה עובד:
• מפעילים חניה באפליקציה בלחיצה אחת (או באריח ב-Quick Settings) ובוחרים
  באיזו אפליקציית חניה השתמשתם.
• ParkStop עוקבת ברקע אחרי חיבור מחדש לבלוטות׳ של הרכב שלכם — האיתות
  העיקרי והמיידי ביותר לכך שחזרתם.
• כגיבוי, היא גם עוקבת אחרי כניסה חזרה לרדיוס סביב מיקום החניה, למקרה
  שאין בלוטות׳ ברכב.
• ברגע שמזוהה שחזרתם — התראה עם צליל, וכפתור לפתיחה ישירה של אפליקציית
  החניה שבחרתם, כדי לעצור אותה תוך שניות.

חשוב לדעת: ParkStop אינה מחוברת ואינה משויכת בשום צורה לפנגו, סלופארק,
EasyPark או כל אפליקציית חניה אחרת. היא לא פותחת, סוגרת או עוצרת חניה
בפועל — היא רק מזהה שחזרתם לרכב ומזכירה לכם לעשות זאת בעצמכם, עם קיצור
דרך נוח.

פרטיות מלאה:
כל המידע — מיקום החניה, זיהוי הבלוטות׳, ההגדרות שלכם — נשאר אך ורק על
המכשיר שלכם. אין שרת, אין ענן, אין חשבון משתמש, ואין שום איסוף או שיתוף
נתונים עם צד שלישי.

תכונות עיקריות:
• זיהוי חזרה לרכב לפי חיבור בלוטות׳ (ודאות גבוהה, מיידי)
• Geofence כאיתות גיבוי כשאין בלוטות׳ זמין
• התראה עם צליל + כפתור לפתיחת אפליקציית החניה
• אפשרות "תזכיר לי עוד 5 דקות"
• Quick Settings Tile להפעלת חניה בלחיצה אחת מבר ההתראות
• מסך יומן Debug שמראה בזמן אמת מה המערכת מזהה
• תמיכה מלאה בעברית ו-RTL
```
